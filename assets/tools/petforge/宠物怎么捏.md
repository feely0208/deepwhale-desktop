# 宠物怎么捏 —— 一句话生成你的专属桌宠

深鲸桌面端支持用 **AI 一句话生成桌宠**：你描述想要的样子，程序自动生成形象、动作、动画，直接出现在桌面角落。

> 本软件**不提供 AI 算力**。生成时调用的是**你自己的**图像生成服务，费用由你的账号承担。
> 好消息是：主流平台都有免费额度，捏几只宠物通常花不到钱。

---

## 一、先搞清楚一件事：需要一个「会画图」的模型

| 模型类型 | 能不能生图 | 说明 |
|---|---|---|
| DeepSeek 系列（`deepseek-flash`、`deepseek-v4-pro` 等） | ❌ **不能** | 文本/视觉理解模型，擅长读文档、写代码、看图，但不产图 |
| 通义万相 / 豆包 Seedream / 智谱 CogView / Kolors / OpenAI gpt-image | ✅ 能 | 这些才是图像生成模型 |

所以：**你平时用的 DeepSeek 模型不能用来捏宠物**，需要单独申请一家生图服务的 Key。

---

## 二、各家 Key 从哪申请（照着点就行）

下面按「上手容易程度」排序，国内手机号即可注册。

### 1. 智谱 CogView（最省事，`cogview-3-flash` 免费）

1. 打开 https://open.bigmodel.cn/
2. 手机号注册登录
3. 进入「API Keys」页：https://open.bigmodel.cn/usercenter/apikeys
4. 点「创建 API Key」，复制生成的 Key（形如 `xxxxx.xxxxx`）
5. 回到软件：生图接口选 **智谱**

### 2. 硅基流动 SiliconFlow（送额度，`Kolors` 画风稳）

1. 打开 https://cloud.siliconflow.cn/
2. 注册（支持手机号 / GitHub）
3. 进入「API 密钥」页：https://cloud.siliconflow.cn/account/ak
4. 新建密钥并复制
5. 软件里生图接口选 **硅基流动**

### 3. 阿里云百炼 · 通义万相（国内最稳，有免费额度）

1. 打开 https://bailian.console.aliyun.com/
2. 用阿里云账号登录（没账号先注册并实名）
3. 首次进入按提示「开通百炼」
4. 右上角头像 →「API-KEY」→ 创建我的 API-KEY
5. 复制 Key（形如 `sk-xxxxxxxx`）
6. 软件里生图接口选 **通义万相**

### 4. 火山引擎 · 豆包 Seedream（出图质量好）

1. 打开 https://console.volcengine.com/ark
2. 用火山引擎账号登录并实名
3. 左侧「开通管理」→ 找到 **Doubao-Seedream** 图像生成模型 → 开通
4. 左侧「API Key 管理」→ 创建 API Key
5. 复制 Key
6. 软件里生图接口选 **豆包**

> ⚠️ 豆包必须先「开通模型」再拿 Key，否则调用会报模型未开通。

### 5. OpenAI（需要国外支付方式）

1. 打开 https://platform.openai.com/api-keys
2. 登录后创建 Secret Key（`sk-...`）
3. 需要账户里有余额（信用卡充值）
4. 软件里生图接口选 **OpenAI**

### 6. Agnes（本软件内置宠物出图用的服务）

1. 打开 https://www.agnes-ai.cn/
2. 注册后在控制台获取 API Key
3. 软件里生图接口选 **Agnes**

## 三、开始捏（三步）

1. **设置 → 宠物 → AI 造宠物**
2. 输入你要的样子，例如：
   - `一只穿法袍戴眼镜的熊猫，抱着一摞卷宗`
   - `一只戴墨镜穿花衬衫的柯基，像个说唱歌手`
   - `一只穿黄马甲戴安全帽的小熊猫建筑工人`
3. 选「动作风格」和「生图接口」，填 API Key，点 **生成宠物**

进度提示会显示「正在生成，约需 30~60 秒」。完成后：
- 宠物自动出现在下方列表
- 点一下就换上
- 状态提示会显示「已生成「xxx」，已加入列表」

**Key 只需要填一次**，之后会自动记住（保存在本机配置里，不上传）。

## 四、怎么写描述，出来的效果最好

程序会自动补上这些要求，但你也可以在描述里强调：

| 要点 | 说明 |
|---|---|
| **纯绿色背景** | 程序靠绿幕原理抠图。如果 AI 画了白底/花纹底，抠出来会有残留 |
| **正面站立全身** | 侧面、半身、坐姿的图做动作会怪 |
| **卡通 Q 版** | 写实风也能用，但缩小到桌面上细节会糊 |
| **不要文字、不要复杂场景** | 道具可以（书、话筒、法槌），但别要背景场景 |
| **指定服装和道具** | 越具体越好：「深红平角领巾」「安全帽」「听诊器」 |

**好例子**：
- `一只穿深灰西装系深红领带的松鼠，戴金丝眼镜，手拿文件夹`
- `一只白大褂配浅蓝口罩的兔子医生，挂听诊器`

**反例**（容易失败）：
- `一只很可爱的宠物`（太笼统，AI 自由发挥）
- `一只在办公室里的猫`（要场景，抠不干净）

## 五、动作风格怎么选

| 风格 | 动作特征 | 适合 |
|---|---|---|
| 通用 | 呼吸、挥手、走动 | 大多数角色 |
| 律师 | 活跃、举手陈述、起身发言 | 律师、法务、销售 |
| 法官 | 沉稳慢半拍、下压（敲槌感） | 法官、仲裁员、领导 |
| 检察官 | 严谨、拍案、翻材料 | 检察官、审核岗 |
| 法警 | 干脆、立正、敬礼、踏步 | 警察、保安、军人 |
| 法医 | 冷静、俯身检查 | 医生、检验、研究 |
| 书记员 | 手快、打字节奏 | 行政、文员、程序员 |
| 厨师 | 颠勺弹跳、翻炒 | 厨师、餐饮、手艺人 |

每个风格都有 **18 种动作 / 105 帧**（待机、挥手、跳跃、冲刺、转身、游泳、睡觉、左右三档移动……）。

## 六、常见问题

**Q：报错「缺少图像生成 API Key」**
按第二节任一平台申请一个，填进 API Key 输入框。

**Q：报错「模型无可用渠道 / 未开通」**
豆包要先在控制台「开通管理」里开通 Seedream 模型；其它平台确认模型名和服务已开通。

**Q：报错 429 / 请求太频繁**
免费额度的速率限制，等几分钟再试。

**Q：抠图有绿色残留 / 边缘毛糙**
描述里强调「纯绿色纯色背景」，或者换一家生图服务再试。不同模型对绿幕的还原度差别挺大。

**Q：生成的宠物不爱动 / 动作怪**
换一个「动作风格」重新生成（不用重新出图也能在宠物目录里换 manifest，但换风格最省事的是重捏）。

**Q：宠物太多，设置页列表太长**
把不用的宠物文件夹从宠物目录里移走即可（设置 → 宠物 → 打开文件夹）。

**Q：我的 Key 会传到你们服务器吗？**
不会。调用直接从你的电脑发到你自己选的图像服务商，本软件只做中间转发和图片处理，Key 保存在本机配置里。

## 七、附：命令行用法（进阶）

不喜欢点界面的话，`petforge.py` 也能直接跑：

```bash
PY="/Applications/DeepWhale Desktop.app/Contents/Resources/office-runtime/dependencies/python/bin/python3"
cd "/Applications/DeepWhale Desktop.app/Contents/Resources/tools/petforge"

"$PY" petforge.py "一只穿法袍戴眼镜的熊猫" --name 熊猫律助 --style lawyer --provider zhipu --api-key 你的key
```

参数说明见同目录 `README.md`。
