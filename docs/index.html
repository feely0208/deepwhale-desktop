快速上手

三个步骤，一分钟上手

1

下载安装

桌面端：在上方选择你的电脑平台下载安装。深鲸 Mobile：下载「深鲸 Mobile APK」（安卓/鸿蒙 4.x），点击安装，首次需允许「未知来源」。

2

启动 DSH

在你的电脑上启动 DeepSeek Harness（npx @deepseek-ai/dsh web），记录它显示的访问地址。

3

连接使用

打开深鲸，填入你的 DSH 地址（同一 WiFi 填局域网地址，异地填你配置的公网地址），即可开始使用。

💡 所有产品都使用你自己的 DeepSeek API Key，数据只存在你自己的设备上，不上传任何服务器。

常见问题

收费吗？

免费开源（MIT）。无内购、无订阅、无广告、无试用期。

需要注册或登录吗？

不需要。每个产品都使用你自己的 DeepSeek API Key，数据只在你自己的设备上。

我的 API Key 安全吗？

由系统钥匙串（safeStorage）加密存储在本机，只在主进程使用，不落明文、不上传。

打开律师端提示「已损坏，无法打开」？

这是 macOS 对未公证应用的统一拦截，安装包本身没有问题。把 App 拖入「应用程序」文件夹后，在终端执行 xattr -cr "/Applications/DeepWhale Lawyer.app"，再打开即可；也可右键点击 App 选「打开」。律师端目前仅支持 Apple 芯片（M1 及以上）Mac。

和 DeepSeek Harness 是什么关系？

本项目是社区产品，基于 DeepSeek Harness 构建，并非 DeepSeek 官方产品，也不代表官方立场。
