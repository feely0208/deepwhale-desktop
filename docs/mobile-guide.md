# 深鲸 Mobile（DeepWhale Mobile）使用指南

## 安装

1. 从 [Releases](https://github.com/feely0208/deepwhale-desktop/releases) 下载 `DeepWhale-Mobile-*.apk`
2. 传输到手机并点击安装
3. 首次安装若提示"未知来源"，请在系统设置中允许

> 适用于安卓系统；鸿蒙（HarmonyOS）4.x 及以下可安装 APK（鸿蒙 NEXT 不支持安卓应用，暂无法使用本 App）。

## 连接你的 DSH

**前提**：你的电脑上运行着 DeepSeek Harness（DSH）服务。

1. 启动 DSH：可直接运行 `npx @deepseek-ai/dsh web`，也可用深鲸桌面端一键启动
2. 记下它显示的访问地址（以你电脑实际显示的为准）
3. 打开深鲸 Mobile App，填入该地址，点击"连接"

> 深鲸桌面与深鲸 Mobile 是两个产品：Mobile 端**不需要安装桌面端**，只需电脑上有 DSH 服务在运行即可。

### ⚠️ 重要：手机连不上是正常的

深鲸桌面启动的 DSH **只在本机运行**（监听 `127.0.0.1`），
**手机无法直接连接，不管是不是同一个 WiFi**。

原因：DSH 的网页界面等同于在你电脑上执行命令，官方出于安全**禁止**它监听网络地址。

所以你还需要自己补一层「转发 + 外部可达」的配置，详见官网指南：**https://deepwhale.org.cn/mobile-guide.html**

### 异地 / 远程（需要你自己配置）

手机不在电脑所在网络时，**需要你自己让手机能够跨网络访问到这台电脑**。

- 这是**由你自行处理**的事项：请自行了解、选择并配置合适的技术方案
- 我们仅说明原理与前提，不指定、不推荐任何具体工具，也不代为配置
- 配置完成后，你会得到一个**手机能访问到**的地址，填进 App 即可

> 提示：把服务暴露到网络涉及安全与费用考量，**务必设置访问认证**，
> 否则等同于把你的电脑交给网络上的任何人。请自行评估风险。

## 数据与隐私

- 深鲸 Mobile App 只负责"打开你填写的地址"，不收集、不上传任何数据
- 你的 API Key 与对话数据仅存在于你自己的 DSH 服务中
- App 本身不存储任何 DeepSeek 凭据

## 常见问题

**Q：连接不上？**
请检查：电脑是否已启动 DSH、填写的地址是否正确、手机与电脑是否在同一网络（局域网场景）。

**Q：App 打开后是空白/白屏？**
多为网络或地址问题，请确认地址可访问（可用手机浏览器先打开该地址测试）。

**Q：为什么 App 里没有某些功能？**
深鲸 Mobile 是"连接你自己的 DSH"的客户端，具体功能取决于你连接的 DSH 服务。
