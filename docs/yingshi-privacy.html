映视投屏隐私政策

生效日期:2026年8月15日 | 开发者:张冬宝

引言

映视投屏(以下简称"本应用")由开发者张冬宝开发并运营。我们深知个人信息对您的重要性,将按照法律法规要求,采取相应安全保护措施,尽力保护您的个人信息安全可控。

核心承诺:本应用为纯本地投屏工具,不收集、不上传任何用户媒体内容。

一、我们收集哪些信息

本应用不收集您的照片、音乐、视频、文档等媒体内容,也不收集通讯录、短信、通话记录等敏感信息。

本应用可能获取以下与功能运行相关的设备信息(仅用于局域网设备发现与投屏):

信息类型用途是否必要
设备型号 / 系统版本投屏兼容性适配必要
网络类型(是否 Wi-Fi)判断能否进行局域网投屏必要
当前 Wi-Fi 名称(SSID)检测与投屏设备是否同一网络必要
局域网内设备信息(电视名称/IP)发现并连接投屏设备必要

上述信息仅在您使用投屏功能时于设备本地处理,不传输至任何服务器。

二、我们如何使用信息

  • 用于发现同一局域网内的投屏设备
  • 用于将您选择的媒体内容直传到您指定的电视/投影(手机与设备间局域网直连)
  • 用于投屏格式兼容性适配(自动转码)

三、信息存储

本应用仅在本地保存少量运行数据(如最近投屏设备名称、投屏续播进度),存储在设备应用私有目录,可随时清除,不进行任何上传。

四、权限说明

权限用途
网络(INTERNET)局域网内与投屏设备通信
获取网络信息(GET_NETWORK_INFO)检测网络状态,判断是否可投屏
获取 Wi-Fi 信息(GET_WIFI_INFO)获取本机 IP/网络名,发现同网段设备
后台运行(KEEP_BACKGROUND_RUNNING)音乐投屏后台持续播放
位置(模糊/精确,仅镜像功能按需)镜像投屏时 Wi-Fi 直连搜索附近设备(按需申请)

文件选择(照片/音乐/视频)均通过系统安全选择器完成,本应用不直接读取您的媒体库,因此不申请媒体库读取权限。

五、第三方 SDK 与数据共享

本应用不集成任何第三方 SDK,不向任何第三方共享、转让或披露您的个人信息。媒体内容仅在您的手机与投屏设备之间通过局域网直传。

六、未成年人保护

本应用为通用工具类应用,不面向未成年人收集信息。

七、您的权利

您可通过应用内"清除投屏历史"、在系统设置中管理权限、卸载应用等方式,控制或删除本应用保存的本地数据。

八、政策更新

本政策如有更新,将在应用内显著位置或应用市场页面提示。
