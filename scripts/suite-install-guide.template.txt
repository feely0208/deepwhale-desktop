深鲸套装 · 安装与使用说明
======================================
包含：① 深鲸桌面（外壳，内含 AI 运行环境）  ② 深鲸·律师端
本说明对应版本：深鲸桌面 {{SHELL_VERSION}} ｜ 深鲸·律师端 {{LAWYER_VERSION}}
支持：macOS（Apple 芯片 / Intel）｜ Windows 10/11 x64 ｜ Linux x64

【这个套装是什么】
  深鲸桌面 = 打开就能用的 AI 桌面外壳（已内置完整运行环境，无需安装 Node.js、无需联网下载）。
  深鲸·律师端 = 面向律师的专业工作台（案件 / 证据 / 文书 / 日历 / 报表）。
  两个配合使用：在深鲸桌面里把会话切到「法律模式」，会自动弹出律师端。

【⚠️ 装之前先看这一条（三个系统都适用）】
  打开深鲸桌面**不会**自动弹出律师端，这是有意设计的：
  只有你在「新建会话」时把预设选成「法律模式」，律师端才会弹出。
  平时用「标准模式」就只是普通的 AI 助手，不会打扰你。

--------------------------------------------------------------------
一、macOS（Apple 芯片 与 Intel 都支持）
--------------------------------------------------------------------
0. 先确认你的 Mac 是哪种芯片：
   左上角  →「关于本机」→ 看「芯片」或「处理器」：
   · Apple M1 / M2 / M3 / M4…（Apple 芯片）→ 用 **arm64** 那两个包
   · Intel Core i5 / i7 / i9（处理器）      → 用 **x64** 那两个包
   （拿不准就用 arm64 试，装不上会明确报错，不会损坏系统）

1. 解压本压缩包，按你的芯片取对应的两个文件：
   - DeepWhale-Desktop-{{SHELL_VERSION}}-arm64.zip   （深鲸桌面 · Apple 芯片）
   - DeepWhale-Lawyer-{{LAWYER_VERSION}}-arm64.zip     （深鲸·律师端 · Apple 芯片）
   或
   - DeepWhale-Desktop-{{SHELL_VERSION}}-x64.zip       （深鲸桌面 · Intel）
   - DeepWhale-Lawyer-{{LAWYER_VERSION}}-x64.zip       （深鲸·律师端 · Intel）
   另加：安装说明.txt

2. 装「深鲸桌面」：
   双击对应架构的 DeepWhale-Desktop-…-zip 解压，得到「DeepWhale Desktop.app」，
   把它拖进左侧的「应用程序」文件夹

3. 装「深鲸·律师端」：
   a) 双击对应架构的 DeepWhale-Lawyer-…-zip 解压，得到「深鲸·律师端-首次使用」文件夹
   b) 打开该文件夹，**先双击里面的「首次使用请双击我」**
      （会闪一个黑窗口，是正常的；它会自动解除 macOS 的安全拦截并启动律师端）
   c) 把「深鲸·律师端.app」拖进「应用程序」文件夹
      —— macOS 把 App 拖进「应用程序」时，系统就自动登记好 deepwhale-law 链接协议，
         不需要再做别的操作

4. 首次打开若提示「已损坏，无法打开」或「无法验证开发者」
   —— 这是没有 Apple 开发者证书时 macOS 的正常提示，文件没有坏。两种办法：
   ① 右键点图标 →「打开」→ 再点一次「打开」
   ② 还是不行，打开「终端」执行：
        xattr -dr com.apple.quarantine "/Applications/DeepWhale Desktop.app"
        xattr -dr com.apple.quarantine "/Applications/深鲸·律师端.app"

5. 打开「深鲸·律师端」，登录并完成激活。

⚠️ 装过旧版的请看这里：
   如果你之前装过名叫「深鲸律师端」（**中间没有「·」**）的旧版本，
   装完新版本后请把「应用程序」里的**旧的那一个删掉**（拖到废纸篓即可）。
   原因：两个版本的 App 名不同，系统的 deepwhale-law 链接协议可能仍指向旧的那个，
   导致在深鲸桌面里选「法律模式」时弹出的是旧版（或什么都不弹）。
   删掉旧版后，重新打开一次新版「深鲸·律师端」即可。
   你的数据不受影响 —— 律师端的数据存在 ~/.deepwhale-legal/ 下，与 App 名无关。

二、Windows 10 / 11（x64）
--------------------------------------------------------------------
1. 解压本压缩包，得到：
   - DeepWhale-Desktop-{{SHELL_VERSION}}-x64-Setup.exe （深鲸桌面安装包）
   - DeepWhale-Lawyer-{{LAWYER_VERSION}}-x64-Setup.exe   （深鲸·律师端安装包）
   - 安装说明.txt

2. 双击 DeepWhale-Desktop-{{SHELL_VERSION}}-x64-Setup.exe，一路点「下一步」装完
   （安装目录保持默认即可，不用改）
   装完自动就有「开始菜单」和「桌面」快捷方式，以后从桌面图标打开就能用。
   ※ 若弹出「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」
     （我们没有购买代码签名证书，这是 Windows 的正常提示，文件没有坏）

3. 双击 DeepWhale-Lawyer-{{LAWYER_VERSION}}-x64-Setup.exe，同样一路「下一步」装完
   （同样会自动创建开始菜单和桌面快捷方式）
   ※ 同样可能弹「Windows 已保护你的电脑」→「更多信息」→「仍要运行」

4. ⚠️ **务必先打开一次律师端**：从「开始菜单」或桌面图标打开「深鲸·律师端」，登录并完成激活。
   为什么要先打开一次：Windows 上的 deepwhale-law 链接协议是律师端
   **第一次运行时**才向系统登记的。只装不打开，协议没登记，
   之后在深鲸桌面里选「法律模式」就不会弹出律师端。
   打开过一次之后，以后就不需要再手动开了。

5. ⚠️ 装过旧版的请看这里：若你之前装过名叫「深鲸律师端」（**中间没有「·」**）的旧版本，
   请先到「设置 → 应用 → 已安装的应用」里把**旧的那个卸载掉**，再装新版。
   原因：App 名不同会并存两份，deepwhale-law 协议可能仍指向旧版，
   导致选「法律模式」时弹出旧版或什么都不弹。数据不受影响（存在 ~/.deepwhale-legal/ 下，与 App 名无关）。

三、Linux（x64）
--------------------------------------------------------------------
1. 解压本压缩包，得到：
   - DeepWhale-Desktop-{{SHELL_VERSION}}-x86_64.AppImage （深鲸桌面，免安装）
   - DeepWhale-Lawyer-{{LAWYER_VERSION}}-x86_64.AppImage   （深鲸·律师端，免安装）
   - 安装说明.txt

2. 两个文件都要先加执行权限。打开「终端」，进入解压出来的目录（例如 cd ~/下载），执行：
     chmod +x DeepWhale-Desktop-{{SHELL_VERSION}}-x86_64.AppImage
     chmod +x DeepWhale-Lawyer-{{LAWYER_VERSION}}-x86_64.AppImage

3. 运行「深鲸桌面」：双击 DeepWhale-Desktop-{{SHELL_VERSION}}-x86_64.AppImage
   （或在终端执行 ./DeepWhale-Desktop-{{SHELL_VERSION}}-x86_64.AppImage）
   建议把这两个 AppImage 放到固定目录（如 ~/Applications）后再用，别留在临时文件夹里。

4. ⚠️ **务必先打开一次律师端**：双击 DeepWhale-Lawyer-{{LAWYER_VERSION}}-x86_64.AppImage，
   登录并完成激活。
   为什么要先打开一次：Linux 上的 deepwhale-law 链接协议是律师端
   **第一次运行时**才写入 ~/.local/share/applications/ 登记的。不打开则不登记，
   之后在深鲸桌面里选「法律模式」就不会弹出律师端。
   打开过一次之后，以后就不需要再手动开了。

--------------------------------------------------------------------
四、怎么用法律模式（三个系统都一样）
--------------------------------------------------------------------
在「深鲸桌面」里，用下面任一方式切到法律模式，律师端就会自动弹出：

  方式 A｜设置里改默认预设（不用先建工作区）
    左下角「设置」→「Agent 预设」→ 在「法律模式」卡片上点「设为默认」
    ✅ 深鲸·律师端立即弹出

  方式 B｜新建会话时选
    点「⊕ 新会话」→ 在输入框上方把预设从「标准模式」改成「法律模式」→ 再开始这个会话
    ✅ 深鲸·律师端立即弹出

  注意：一个会话一旦开始，它的预设就固定了。如果这个会话已经聊过，
       再切预设不会生效 —— 这时请新建一个会话来选，或直接用方式 A。

  说明：默认始终是「标准模式」，打开深鲸桌面不会自动弹律师端；
       从法律模式切回标准/极简等模式时是静默的，不会重复弹。

  提示：若切了法律模式但律师端没弹，深鲸桌面现在会明确告诉你原因
       （未安装 / 从未打开过 / 已被移走），并给出「去下载律师端」的入口。

五、常见问题
--------------------------------------------------------------------
Q：我选了「法律模式」但律师端没弹？
A：依次检查：
   ① 律师端是否**至少打开过一次**（Windows / Linux 必须，否则协议没登记）；
   ② 律师端是否已完成激活；
   ③ 深鲸桌面是否已经在运行（冷启动时等界面出来再切）；
   ④ Windows 可在 PowerShell 执行 `reg query HKCU\Software\Classes\deepwhale-law` 看协议是否登记。

Q：会一打开就自动弹律师端吗？
A：不会，也不应该。只有你主动切到法律模式才会弹。

Q：律师端能单独打开吗？
A：可以，它是独立应用，直接双击也能用（不依赖深鲸桌面）。

Q：深鲸桌面需要装 Node.js 吗？需要联网下载运行环境吗？
A：都不需要。运行环境已经打进包里，装完即用（首次打开只需联网登录 / 填 API Key）。

Q：能让它直接生成 Word / Excel / PPT / PDF 吗？
A：可以。直接说「把这些内容排版成一份 Word 公文」这类话即可，深鲸桌面内置了
   文档生成与 PDF 渲染能力，并自带中文公文排版规范（仿宋、A4、页码等），
   不需要额外安装任何东西。

Q：我的数据在哪？
A：会话与设置保存在本机：
   macOS   ~/Library/Application Support/DeepWhale Desktop/
   Windows %APPDATA%\DeepWhale Desktop\
   Linux   ~/.config/DeepWhale Desktop/
   深鲸桌面使用自己独立的运行目录，不会改动你电脑上其它 DeepSeek Harness 的配置。

【数据与隐私】
  会话与设置都保存在本机，不会上传。模型请求由你的 API Key 直接发往 DeepSeek。
