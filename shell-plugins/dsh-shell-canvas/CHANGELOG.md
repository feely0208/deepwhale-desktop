## 1.0.6 —— 修复宿主半边缺 import（严重）
- `lib/index.js` 用了 `pathToFileURL`（共 8 处）却从未 import `node:url`，
  每处调用都抛 `pathToFileURL is not defined`。受影响：环境自检（ffmpeg 检测）、
  生产者/提供者加载、提供者列表、批量任务 —— **宿主半边这些功能全不可用**。
- 表现：插件面板恒显「⚠️ 没找到 ffmpeg —— 出片必须用它」，与本机是否装了 ffmpeg 无关。
- 修复：补 `import { pathToFileURL } from 'node:url';`
- 影响版本：1.0.1 ~ 1.0.5（npm 上 1.0.5 同此 bug）。CLI 路径不受影响，所以命令行出片一直正常。

## 1.0.3 —— 授权机制重做
- 授权校验从**对称 HMAC**改为 **Ed25519 非对称验签**
- 起因：旧版把对称密钥内嵌在插件里，等于把"签发权"一起发给了用户 ——
  任何解包读出密钥的人都能自造无限张 ¥199 授权码
- 现在：私钥只在服务器（`canvas-license-key.pem`，600 权限），插件只带公钥，**伪造不出授权码**
- 附带：移除失效的自备字体接口（浏览器 file:// 下字体加载被 CORS 拦，实测不通）
- 打包瘦身：过滤 `.ts` / `.map` / 测试目录，目录体积 4708KB → 3492KB
