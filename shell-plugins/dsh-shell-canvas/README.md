# 深鲸画布 · DSH 插件

把一段文字，变成能发的视频。

贴一段稿子、选几张素材，点一下出横竖双版成片。
**稿子、素材、成片都在你自己的电脑上** —— 不上传、不联网，拔掉网线照样出片。

## 安装

在你所用的、支持 DSH 的载体里打开「插件管理器」，选择**从压缩包安装**，选中下载好的 `.tgz` 即可。

命令行安装：

```bash
# 推荐：从 npm 装（始终取最新版，不钉版本号）
dsh plugin add @deepwhale-cn/dsh-shell-canvas
```

也可以从官网下载插件包后，在插件管理器里「从压缩包安装」：
<https://www.deepwhale.org.cn/download.html>


装完无需重启，界面跟随所在载体的外观。

## 能力

- **一次出三种版式** —— 旁白口播 / 金句引用 / 步骤清单，编排各不相同
- **逐句指定配图** —— 分镜表里逐句安排素材与时长，素材与字幕一一对应
- **一个位置放多张图或一段视频** —— 多图按时间轮播；视频素材会让画面真的动起来
- **每个镜头换版位** —— 尺寸、位置、入场方式逐镜轮换
- **一次出横竖双版** —— 同一份稿子，横版竖版一起给
- **模型不绑任何一家** —— 生图与配音接你自己的接口，密钥留在本机
- **批量出片** —— 一次丢进一整批；一条出错不拖垮整批
- **跨平台** —— macOS / Windows / Linux
